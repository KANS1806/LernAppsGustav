# Unterrichts-Apps

Interaktive Übungs-Apps für den Unterricht (Mathematik, Naturwissenschaften, Physik).
Jede App ist eine einzelne HTML-Datei ohne externe Abhängigkeiten – die Schriften liegen im Ordner `fonts`.
Die Apps übertragen keine Daten; manche merken sich den Lernstand nur im Browser des Geräts.

- `index.html` – Startseite mit allen Apps
- `links.html` – Links und QR-Codes für Lehrkräfte
